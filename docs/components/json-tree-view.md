# JsonTreeView

Inspect JSON and JavaScript values in an expandable tree.

Port of `moduix/packages/svelte/src/components/json-tree-view` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Installation

```sh
pnpm add rta-ui
```

`rta-ui` ships one flat export surface, plus the tokens in `rta-ui/style.css`:

```svelte
<script lang="ts">
	import { JsonTreeView } from 'rta-ui';
	import 'rta-ui/style.css';
</script>
```

## Overview example source

```svelte
	const deployment = {
		environment: 'production',
		release: { branch: 'main', commit: '0f4c9d7', status: 'ready' },

<JsonTreeView data={deployment} defaultExpandedDepth={2}>
	<JsonTreeViewTree indentGuide />

```

## Behaviour covered by tests

- renders the Ark contract for the root, tree and generated nodes
- :
- expands nested objects and arrays and reports the expanded values
- keyboard navigation moves between generated nodes and expands on ArrowRight
- preview options shape the rendered values
- a filtered value only renders the surviving entries
- re-seeds expansion to the default depth when the inspected value is replaced
- renders custom values and indent guides
- drives the generated tree from an api created outside the parts
