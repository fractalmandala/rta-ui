# Components

87 component families, all dependency-free. Each page is generated from its source, demo and tests.

## Pure

- [Alert](./alert.md) — Show an inline status message with a title, description, and actions.
- [AspectRatio](./aspect-ratio.md) — Keep images, video, and embeds at a fixed width-to-height ratio.
- [Avatar](./avatar.md) — Show a user’s photo, with initials while it loads or if it fails.
- [Badge](./badge.md) — Label a status, category, version, or count in a small chip.
- [Bleed](./bleed.md) — Let a banner or image extend past the padding of its container.
- [Breadcrumbs](./breadcrumbs.md) — Show where a page sits in the site hierarchy with links back up.
- [Button](./button.md) — Trigger an action or follow a link with accessible button styles.
- [Card](./card.md) — Group a title, content, and actions on one surface.
- [CloseButton](./close-button.md) — Dismiss a notification, card, or overlay with an accessible icon button.
- [Container](./container.md) — Center page content at a readable width with responsive side padding.
- [Empty](./empty.md) — Fill an empty list or first-run screen with a message and next steps.
- [Heading](./heading.md) — Title a page or section with the right level and visual size.
- [Highlight](./highlight.md) — Mark the words that match a search query inside a piece of text.
- [Image](./image.md) — Serve responsive images with srcset generated for common CDNs.
- [Input](./input.md) — Collect a single line of text with native input behavior.
- [InputGroup](./input-group.md) — Add prefixes, suffixes, and inline buttons around an input.
- [Kbd](./kbd.md) — Show a keyboard key or a shortcut inline with the surrounding text.
- [List](./list.md) — Render bulleted or numbered lists with consistent spacing and markers.
- [Marquee](./marquee.md) — Scroll logos or announcements in a continuous loop.
- [ProgressCircular](./progress-circular.md) — Show task progress in a compact ring, with a known or unknown end.
- [ProgressLinear](./progress-linear.md) — Show task progress on a bar, with a known or unknown end.
- [Separator](./separator.md) — Draw a line between related sections, horizontal or vertical.
- [SimpleGrid](./simple-grid.md) — Lay out cards and tiles in equal columns that adapt to the width.
- [Skeleton](./skeleton.md) — Hold the place of text, cards, and media while content loads.
- [Spinner](./spinner.md) — Signal a short wait in buttons, rows, and compact states.
- [Stack](./stack.md) — Arrange items in a row or column with even spacing.
- [Swap](./swap.md) — Animate between two icons or labels when a control changes state.
- [Table](./table.md) — Present rows of data with headers, captions, and numeric columns.
- [Tag](./tag.md) — Show a selected value, filter, or assignment as a removable token.
- [Text](./text.md) — Set body text, captions, and inline copy on the type scale.
- [Textarea](./textarea.md) — Collect several lines of text, with optional auto-resize.
- [Typeset](./typeset.md) — Style rendered Markdown, CMS content, and AI answers for reading.

- [Switch](./switch.md) — Turn a setting on or off with an immediate effect.
- [Tabs](./tabs.md) — Switch between related panels in one area of the page.
- [TagsInput](./tags-input.md) — Enter a list of short values as tags that users can edit or remove.
- [Timer](./timer.md) — Count elapsed or remaining time with start, pause, and reset.
- [Toggle](./toggle.md) — Press a button to turn an option on and press again to turn it off.
- [ToggleGroup](./toggle-group.md) — Group toggle buttons for one or several choices, like text alignment.
