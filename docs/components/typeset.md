# Typeset

Style rendered Markdown, CMS content, and AI answers for reading.

Port of `moduix/packages/svelte/src/components/typeset` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Parts

| export | file |
| --- | --- |
| `Typeset` | `Typeset.svelte` |
| `TypesetScroll` | `TypesetScroll.svelte` |

## Props

Every part accepts its native element props plus `class`, `style`, `ref` and `asChild`.

## Styling hooks

| part file | `data-scope` | `data-part` | `data-slot` |
| --- | --- | --- | --- |
| `Typeset` | `typeset` | `root` | `typeset-root` |
| `TypesetScroll` | `typeset` | `scroll` | `typeset-scroll` |

Custom properties read by this family’s CSS Module:

- `--moduix-typeset-flow`
- `--moduix-typeset-font-body`
- `--moduix-typeset-font-heading`
- `--moduix-typeset-font-mono`
- `--moduix-typeset-leading`
- `--moduix-typeset-size`

## Usage

The gallery demo, verbatim:

```svelte
<script lang="ts">
  import { Typeset } from 'rta-ui';
</script>

<Typeset>
  <h1>Typeset</h1>
  <p>
    Unstyled HTML becomes readable prose. Every child is styled by the typeset root, so markdown
    output needs no per-tag classes.
  </p>
  <h2>Nested headings</h2>
  <ul>
    <li>Lists keep their markers</li>
    <li>Code spans such as <code>cn()</code> stay inline</li>
  </ul>
  <blockquote>A quiet quote.</blockquote>
  <pre><code>const value = 1;</code></pre>
</Typeset>
```

## Notes

- **Parity:** accepted deviation — Every family root slot is `<family>-root`, so `typeset` was renamed.
