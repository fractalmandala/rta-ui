# Separator

Draw a line between related sections, horizontal or vertical.

Port of `moduix/packages/svelte/src/components/separator` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Usage

The gallery demo, verbatim:

```svelte

  import { Separator } from 'rta-ui';
</script>

<div>
  <p>Above</p>
  <Separator />
  <p>Below</p>
</div>
<div class="row">
  <span>Left</span>
  <Separator orientation="vertical" />
  <span>Right</span>
</div>

<style>
  .row {
    display: flex;
    gap: 0.75rem;
    align-items: center;
    height: 2rem;
    margin-top: 1rem;
  }
</style>
```

## Behaviour covered by tests

- is a horizontal separator by default
- reports a vertical orientation
- drops role and aria-orientation when the caller takes over the role
