# AspectRatio

Keep images, video, and embeds at a fixed width-to-height ratio.

Port of `moduix/packages/svelte/src/components/aspect-ratio` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Installation

```sh
pnpm add rta-ui
```

`rta-ui` ships one flat export surface, plus the tokens in `rta-ui/style.css`:

```svelte
<script lang="ts">
	import { AspectRatio } from 'rta-ui';
	import 'rta-ui/style.css';
</script>
```
