# Input

Collect a single line of text with native input behavior.

Port of `moduix/packages/svelte/src/components/input` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Parts

| export | file |
| --- | --- |
| `Input` | `Input.svelte` |

## Props

### `Input` — `InputRootProps`
adds to `Omit<HTMLInputAttributes, 'size'>`.

| prop | type | default | notes |
| --- | --- | --- | --- |
| `htmlSize` | `number` | — | Native `size` attribute, which the `size` prop shadows for the token scale. |
| `size` | `InputSize` | `'md'` |  |
| `ref` | `HTMLInputElement \| null` | — | bindable |

## Usage

The gallery demo, verbatim:

```svelte
<script lang="ts">
  import { Input, Textarea } from 'rta-ui';

  let name = $state('Amrit');
  let bio = $state('Svelte, CSS, and a little Rust.');
</script>

<div class="stack">
  <label class="field">
    <span>Name</span>
    <Input bind:value={name} placeholder="Name" />
  </label>
  <label class="field">
    <span>Read only</span>
    <Input value="read only" readonly size="sm" />
  </label>
  <label class="field">
    <span>Invalid</span>
    <Input value="invalid" aria-invalid="true" />
  </label>
  <label class="field">
    <span>Bio</span>
    <Textarea bind:value={bio} rows={3} placeholder="Bio" />
  </label>
  <p class="echo">{name} · {bio}</p>
</div>

<style>
  .stack {
    display: grid;
    gap: 0.75rem;
    max-width: 22rem;
  }
  .field {
    display: grid;
    gap: 0.25rem;
    font-size: 0.75rem;
    font-weight: 500;
  }
  .echo {
    font-size: 0.75rem;
    color: var(--moduix-muted-foreground);
  }
</style>
```

## Behaviour covered by tests

- an input carries the field hooks and the token size
- the native size attribute moves to htmlSize
- typing writes the bound value back
- a textarea keeps its own part and writes back its value

## Notes

- **Parity:** `data-slot` hooks match moduix exactly (`pnpm parity`).
