# Collapsible

Show and hide one region of content with a trigger.

Port of `moduix/packages/svelte/src/components/collapsible` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Installation

```sh
pnpm add rta-ui
```

`rta-ui` ships one flat export surface, plus the tokens in `rta-ui/style.css`:

```svelte
<script lang="ts">
	import { Collapsible } from 'rta-ui';
	import 'rta-ui/style.css';
</script>
```

## Overview example source

The component above is this file, unchanged:

```svelte
<script lang="ts">
	import {
		Collapsible,
		CollapsibleContent,
		CollapsibleIndicator,
		CollapsibleTrigger
	} from 'rta-ui';
</script>

<Collapsible defaultOpen>
	<CollapsibleTrigger>
		What is rta ui?
		<CollapsibleIndicator />
	</CollapsibleTrigger>
	<CollapsibleContent>
		A dependency-free Svelte 5 component library with Ark-compatible data attributes.
	</CollapsibleContent>
</Collapsible>
```

## Behaviour covered by tests

- renders the ark contract
- toggles content and reports open changes
- honours the collapsed size instead of hiding
- does not toggle while disabled
