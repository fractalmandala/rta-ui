# Swap

Animate between two icons or labels when a control changes state.

Port of `moduix/packages/svelte/src/components/swap` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Installation

```sh
pnpm add rta-ui
```

`rta-ui` ships one flat export surface, plus the tokens in `rta-ui/style.css`:

```svelte
<script lang="ts">
	import { Swap } from 'rta-ui';
	import 'rta-ui/style.css';
</script>
```

## Overview example source

The component above is this file, unchanged:

```svelte
<script lang="ts">
	import { Swap, SwapIndicator } from 'rta-ui';

	let swap = $state(false);
</script>

<Swap bind:swap animation="fade">
	<SwapIndicator type="on">Close</SwapIndicator>
	<SwapIndicator type="off">Open</SwapIndicator>
</Swap>
<button type="button" onclick={() => (swap = !swap)}>Toggle</button>
```

## Behaviour covered by tests

- renders the ark contract with the off indicator visible
- swapping flips the indicators
