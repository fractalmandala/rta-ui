# SplitButton

Run a primary action or pick a related one from an attached menu.

Port of `moduix/packages/svelte/src/components/split-button` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Installation

```sh
pnpm add rta-ui
```

`rta-ui` ships one flat export surface, plus the tokens in `rta-ui/style.css`:

```svelte
<script lang="ts">
	import { SplitButton } from 'rta-ui';
	import 'rta-ui/style.css';
</script>
```

## Overview example source

The component above is this file, unchanged:

```svelte
<script lang="ts">
	import {
		MenuItem,
		MenuItemShortcut,
		SplitButton,
		SplitButtonAction,
		SplitButtonContent,
		SplitButtonPositioner,
		SplitButtonTrigger
	} from 'rta-ui';
</script>

<SplitButton variant="outline" aria-label="Document">
	<SplitButtonAction>Save</SplitButtonAction>
	<SplitButtonTrigger />
	<SplitButtonPositioner>
		<SplitButtonContent>
			<MenuItem value="save-as">
				Save as…
				<MenuItemShortcut>⇧⌘S</MenuItemShortcut>
			</MenuItem>
			<MenuItem value="export">Export</MenuItem>
			<MenuItem value="archive" disabled>Archive</MenuItem>
		</SplitButtonContent>
	</SplitButtonPositioner>
</SplitButton>
```

## Behaviour covered by tests

- composes a group of a Button action and an attached menu trigger
- the shared size and variant reach both buttons
- the attached trigger opens the menu family content in its own positioner
- selecting an item closes the menu, reports the value and restores focus to the trigger
- the main action is independent of the menu
- disabling the action does not affect the menu, and a disabled trigger cannot open it
