# InputGroup

Add prefixes, suffixes, and inline buttons around an input.

Port of `moduix/packages/svelte/src/components/input-group` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Installation

```sh
pnpm add rta-ui
```

`rta-ui` ships one flat export surface, plus the tokens in `rta-ui/style.css`:

```svelte
<script lang="ts">
	import { InputGroup } from 'rta-ui';
	import 'rta-ui/style.css';
</script>
```

## Overview example source

The component above is this file, unchanged:

```svelte
<script lang="ts">
  import {
    InputGroup,
    InputGroupAddon,
    InputGroupClearTrigger,
    InputGroupInput,
    InputGroupText,
  } from 'rta-ui';

  let amount = $state('42.00');
</script>

<div class="stack">
  <InputGroup size="md">
    <InputGroupAddon align="inline">
      <InputGroupText>$</InputGroupText>
    </InputGroupAddon>
    <InputGroupInput bind:value={amount} placeholder="0.00" aria-label="Amount" />
    <InputGroupAddon align="inline">
      <InputGroupText>USD</InputGroupText>
    </InputGroupAddon>
    <InputGroupAddon align="inline">
      <InputGroupClearTrigger onclick={() => (amount = '')} />
    </InputGroupAddon>
  </InputGroup>
  <InputGroup size="sm">
    <InputGroupInput placeholder="Compact group" aria-label="Compact group" />
  </InputGroup>
</div>

<style>
  .stack {
    display: grid;
    gap: 0.5rem;
    max-width: 22rem;
  }
</style>
```

## Behaviour covered by tests

- the group size reaches the addon, the input and the clear trigger
- an input inside a group keeps md without a group
- addons expose their alignment and text parts
- the clear trigger is a labelled button that shares the group size
