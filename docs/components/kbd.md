# Kbd

Show a keyboard key or a shortcut inline with the surrounding text.

Port of `moduix/packages/svelte/src/components/kbd` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Installation

```sh
pnpm add rta-ui
```

`rta-ui` ships one flat export surface, plus the tokens in `rta-ui/style.css`:

```svelte
<script lang="ts">
	import { Kbd } from 'rta-ui';
	import 'rta-ui/style.css';
</script>
```

## Keyboard

No keys are intercepted: the family keeps the native keyboard behaviour of the elements it renders.

## Overview example source

The component above is this file, unchanged:

```svelte
<script lang="ts">
  import { Kbd } from 'rta-ui';
</script>

<p>Press <Kbd>⌘</Kbd> <Kbd>K</Kbd> to search, or <Kbd>Shift</Kbd> + <Kbd>Enter</Kbd> to send.</p>
```
