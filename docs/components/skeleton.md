# Skeleton

Hold the place of text, cards, and media while content loads.

Port of `moduix/packages/svelte/src/components/skeleton` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Usage

The gallery demo, verbatim:

```svelte
<script lang="ts">
  import { Skeleton } from 'rta-ui';
</script>

<div class="card">
  <Skeleton width={48} height={48} borderRadius="50%" />
  <div class="lines">
    <Skeleton width="60%" height={14} />
    <Skeleton width="90%" height={14} />
    <Skeleton width="40%" height={14} />
  </div>
</div>

<style>
  .card {
    display: flex;
    gap: 0.75rem;
    padding: 1rem;
    border: 1px solid var(--moduix-border);
    border-radius: 0.75rem;
  }
  .lines {
    display: grid;
    gap: 0.5rem;
    flex: 1;
  }
</style>
```

## Behaviour covered by tests

- is a loading pulse hidden from assistive tech by default
- loaded skeletons expose no hidden or loading hooks
- turns numeric dimensions into pixel styles
