# Toggle

Press a button to turn an option on and press again to turn it off.

Port of `moduix/packages/svelte/src/components/toggle` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Installation

```sh
pnpm add rta-ui
```

`rta-ui` ships one flat export surface, plus the tokens in `rta-ui/style.css`:

```svelte
<script lang="ts">
	import { Toggle } from 'rta-ui';
	import 'rta-ui/style.css';
</script>
```

## Keyboard

No keys are intercepted: the family keeps the native keyboard behaviour of the elements it renders.

## Overview example source

The component above is this file, unchanged:

```svelte
<script lang="ts">
	import { Toggle } from 'rta-ui';

	let bold = $state(false);
</script>

<Toggle bind:pressed={bold} variant="outline">
	Bold
</Toggle>
<Toggle pressed>Italic</Toggle>
<Toggle disabled>Underline</Toggle>
```

## Behaviour covered by tests

- renders the ark contract
- toggles and reports onPressedChange
- disabled blocks interaction
- renders the ark contract
- single mode replaces the selection
- deselectable false keeps at least one value
- multiple mode appends values and uses a group role
- arrow keys move roving focus and skip disabled items
- vertical orientation ignores horizontal arrows
