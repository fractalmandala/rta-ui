## Usage

The gallery demo, verbatim:

```svelte
<script lang="ts">
	import {
		Field,
		FieldLabel,
		FieldHelperText,
		FieldRequiredIndicator
	} from 'rta-ui';
	import { NativeSelect } from 'rta-ui';
	import { Fieldset, FieldsetLegend, FieldsetHelperText } from 'rta-ui';
	import { Input } from 'rta-ui';
</script>

<Fieldset>
	<FieldsetLegend>Shipping address</FieldsetLegend>
	<FieldsetHelperText>Where the order should arrive.</FieldsetHelperText>

	<Field id="address-line">
		<FieldLabel>Street</FieldLabel>
		<Input placeholder="12 Orchard Lane" />
	</Field>

	<Field id="address-country" required>
		<FieldLabel>
			Country
			<FieldRequiredIndicator />
		</FieldLabel>
		<NativeSelect value="nz">
			<option value="au">Australia</option>
			<option value="nz">New Zealand</option>
			<option value="jp">Japan</option>
		</NativeSelect>
		<FieldHelperText>We ship within these regions only.</FieldHelperText>
	</Field>
</Fieldset>
```

## Behaviour covered by tests

- renders the Ark contract
- disables the native fieldset and cascades to a nested field
- renders error text with aria-live only when invalid
- wires aria-describedby to helper and error text after mount
