# Highlight

Mark the words that match a search query inside a piece of text.

Port of `moduix/packages/svelte/src/components/highlight` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Usage

The gallery demo, verbatim:

```svelte
<script lang="ts">
	import { Highlight } from 'rta-ui';
</script>

<p>
	<Highlight text="Runes make Svelte state explicit" query="state" />
</p>
<p>
	<Highlight text="Match state and states with exact words" query={['state', 'words']} matchAll />
</p>
```

## Behaviour covered by tests

- splits text into matched and unmatched chunks
- respects ignoreCase and exactMatch
- highlights every query
- requires matchAll for array queries
- renders marks for matches only
