# Switch

Turn a setting on or off with an immediate effect.

Port of `moduix/packages/svelte/src/components/switch` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Installation

```sh
pnpm add rta-ui
```

`rta-ui` ships one flat export surface, plus the tokens in `rta-ui/style.css`:

```svelte
<script lang="ts">
	import { Switch } from 'rta-ui';
	import 'rta-ui/style.css';
</script>
```

## Overview example source

The component above is this file, unchanged:

```svelte
<script lang="ts">
	import { Switch, SwitchControl, SwitchLabel } from 'rta-ui';

	let checked = $state(true);
</script>

<Switch bind:checked>
	<SwitchControl />
	<SwitchLabel>Email notifications</SwitchLabel>
</Switch>
<p>{checked ? 'On' : 'Off'}</p>
```

## Behaviour covered by tests

- renders the ark contract
- toggles on input click and reports onCheckedChange
- honours the controlled checked prop
- disabled blocks interaction
- readOnly blocks interaction
- hover and focus are reflected as data attributes
- sizes map to data-size
