# QrCode

Turn a link or text into a QR code that users can scan or download.

Port of `moduix/packages/svelte/src/components/qr-code` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Installation

```sh
pnpm add rta-ui
```

`rta-ui` ships one flat export surface, plus the tokens in `rta-ui/style.css`:

```svelte
<script lang="ts">
	import { QrCode } from 'rta-ui';
	import 'rta-ui/style.css';
</script>
```

## Overview example source

The component above is this file, unchanged:

```svelte
<script lang="ts">
	import { QrCode, QrCodeDownloadTrigger, QrCodeFrame, QrCodePattern } from 'rta-ui';
</script>

<div style="display: flex; flex-wrap: wrap; gap: 1.5rem; align-items: start">
	<QrCode value="https://rta.ui" style="--moduix-qr-code-size: 10rem">
		<QrCodeFrame>
			<QrCodePattern />
		</QrCodeFrame>
		<QrCodeDownloadTrigger fileName="rta-ui-qr">Download</QrCodeDownloadTrigger>
	</QrCode>

	<QrCode value="rta ui — dependency-free Svelte 5" pixelSize={4} style="--moduix-qr-code-size: 10rem">
		<QrCodeFrame>
			<QrCodePattern />
		</QrCodeFrame>
	</QrCode>
</div>
```
