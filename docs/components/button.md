# Button

Trigger an action or follow a link with accessible button styles.

Port of `moduix/packages/svelte/src/components/button` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Installation

```sh
pnpm add rta-ui
```

`rta-ui` ships one flat export surface, plus the tokens in `rta-ui/style.css`:

```svelte
<script lang="ts">
	import { Button } from 'rta-ui';
	import 'rta-ui/style.css';
</script>
```

## Behaviour covered by tests

- defaults to a plain button element with type=button
- marks a loading button busy and disabled, and swallows its click
- a disabled button does not fire its click handler
- passes clicks through when enabled
- leaves type and disabled to the composed element in asChild
- a loading asChild button still announces itself busy
