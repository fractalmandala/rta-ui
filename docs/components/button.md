## Behaviour covered by tests

- defaults to a plain button element with type=button
- marks a loading button busy and disabled, and swallows its click
- a disabled button does not fire its click handler
- passes clicks through when enabled
- leaves type and disabled to the composed element in asChild
- a loading asChild button still announces itself busy
