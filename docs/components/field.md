## Usage

The gallery demo, verbatim:

```svelte
<script lang="ts">
	import {
		Field,
		FieldLabel,
		FieldHelperText,
		FieldErrorText,
		FieldRequiredIndicator
	} from 'rta-ui';
	import { NativeSelect } from 'rta-ui';

	let value = $state('apple');
	let invalid = $state(false);
</script>

<Field id="fruit" required {invalid}>
	<FieldLabel>
		Favourite fruit
		<FieldRequiredIndicator />
	</FieldLabel>
	<NativeSelect bind:value>
		<option value="apple">Apple</option>
		<option value="banana">Banana</option>
		<option value="cherry">Cherry</option>
	</NativeSelect>
	<FieldHelperText>Choose the fruit you like most.</FieldHelperText>
	<FieldErrorText>Please choose a fruit.</FieldErrorText>
</Field>

<button type="button" onclick={() => (invalid = !invalid)}>Toggle invalid</button>
```

## Behaviour covered by tests

- renders the Ark contract
- propagates invalid state to a nested select and renders error text
- hides error text when valid
- shows the required indicator only when required
- wires aria-describedby to helper and error text after mount
- inherits disabled from the control
