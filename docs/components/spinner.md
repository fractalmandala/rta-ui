## Usage

The gallery demo, verbatim:

```svelte
<script lang="ts">
  import { Button, Spinner } from 'rta-ui';
</script>

<div class="row">
  <Spinner size="xs" />
  <Spinner size="sm" />
  <Spinner size="md" />
  <Spinner size="lg" />
  <Spinner size="xl" />
  <Button loading>
    <Spinner size="sm" decorative />
    Saving
  </Button>
</div>

<style>
  .row {
    display: flex;
    gap: 0.75rem;
    align-items: center;
  }
</style>
```

## Behaviour covered by tests

- announces itself as a status with a default label
- renders an indicator and a ring that are hidden from assistive tech
- a decorative spinner leaves no role and no label
- a labelled spinner keeps the caller label
