# Spinner

Signal a short wait in buttons, rows, and compact states.

Port of `moduix/packages/svelte/src/components/spinner` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Installation

```sh
pnpm add rta-ui
```

`rta-ui` ships one flat export surface, plus the tokens in `rta-ui/style.css`:

```svelte
<script lang="ts">
	import { Spinner } from 'rta-ui';
	import 'rta-ui/style.css';
</script>
```

## Overview example source

The component above is this file, unchanged:

```svelte
<script lang="ts">
  import { Button, Spinner } from 'rta-ui';
</script>

<div class="row">
  <Spinner size="xs" />
  <Spinner size="sm" />
  <Spinner size="md" />
  <Spinner size="lg" />
  <Spinner size="xl" />
  <Button loading>
    <Spinner size="sm" decorative />
    Saving
  </Button>
</div>

<style>
  .row {
    display: flex;
    gap: 0.75rem;
    align-items: center;
  }
</style>
```

## Behaviour covered by tests

- announces itself as a status with a default label
- renders an indicator and a ring that are hidden from assistive tech
- a decorative spinner leaves no role and no label
- a labelled spinner keeps the caller label
