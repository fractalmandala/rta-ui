## Usage

The gallery demo, verbatim:

```svelte
<script lang="ts">
	import { Avatar, AvatarFallback, AvatarGroup, AvatarImage } from 'rta-ui';
</script>

<Avatar size="lg">
	<AvatarImage src="https://i.pravatar.cc/120?img=12" alt="Ada Lovelace" />
	<AvatarFallback>AL</AvatarFallback>
</Avatar>

<AvatarGroup>
	{#each ['AL', 'GH', 'KL'] as initials (initials)}
		<Avatar>
			<AvatarFallback>{initials}</AvatarFallback>
		</Avatar>
	{/each}
</AvatarGroup>
```

## Behaviour covered by tests

- renders the ark contract
- loading the image reveals it and hides the fallback
- image error keeps the fallback visible
