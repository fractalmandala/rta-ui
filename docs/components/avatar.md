# Avatar

Show a user’s photo, with initials while it loads or if it fails.

Port of `moduix/packages/svelte/src/components/avatar` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Installation

```sh
pnpm add rta-ui
```

`rta-ui` ships one flat export surface, plus the tokens in `rta-ui/style.css`:

```svelte
<script lang="ts">
	import { Avatar } from 'rta-ui';
	import 'rta-ui/style.css';
</script>
```

## Overview example source

The component above is this file, unchanged:

```svelte
<script lang="ts">
	import { Avatar, AvatarFallback, AvatarGroup, AvatarImage } from 'rta-ui';
</script>

<Avatar size="lg">
	<AvatarImage src="https://i.pravatar.cc/120?img=12" alt="Ada Lovelace" />
	<AvatarFallback>AL</AvatarFallback>
</Avatar>

<AvatarGroup>
	{#each ['AL', 'GH', 'KL'] as initials (initials)}
		<Avatar>
			<AvatarFallback>{initials}</AvatarFallback>
		</Avatar>
	{/each}
</AvatarGroup>
```

## Behaviour covered by tests

- renders the ark contract
- loading the image reveals it and hides the fallback
- image error keeps the fallback visible
