# Progress

Shared state module rather than a component: there is no markup of its own. The visual families built on it are `progress-linear` and `progress-circular`, which reuse these types and the `createProgress` factory.

## Exports

- `createProgress`
- `setProgressContext`
- `useProgressContext`
- `ProgressApi`
- `ProgressValueChangeDetails`
- `ProgressValueTextDetails`
- `UseProgressProps`

## Generated ids

- `progress:${id}`


## Behaviour covered by tests

- renders the ark contract
- indeterminate progress omits the numeric value
- completing reports the complete state
- vertical progress fills by height
- circular progress renders the ring geometry

## Notes

- **Parity:** moduix has no `progress` family; this is an rta-ui family, so nothing is compared.
