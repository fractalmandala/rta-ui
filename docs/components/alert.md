# Alert

Show an inline status message with a title, description, and actions.

Port of `moduix/packages/svelte/src/components/alert` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Installation

```sh
pnpm add rta-ui
```

`rta-ui` ships one flat export surface, plus the tokens in `rta-ui/style.css`:

```svelte
<script lang="ts">
	import { Alert } from 'rta-ui';
	import 'rta-ui/style.css';
</script>
```

## Overview example source

The component above is this file, unchanged:

```svelte
<script lang="ts">
  import { Alert } from 'rta-ui';
</script>

<div class="stack">
  <Alert status="info">A new version is available.</Alert>
  <Alert status="success">Your changes were saved.</Alert>
  <Alert status="warning">This action cannot be undone.</Alert>
  <Alert status="error">The connection was refused.</Alert>
</div>

<style>
  .stack {
    display: grid;
    gap: 0.5rem;
  }
</style>
```
