# Image

Serve responsive images with srcset generated for common CDNs.

Port of `moduix/packages/svelte/src/components/image` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Installation

```sh
pnpm add rta-ui
```

`rta-ui` ships one flat export surface, plus the tokens in `rta-ui/style.css`:

```svelte
<script lang="ts">
	import { Image } from 'rta-ui';
	import 'rta-ui/style.css';
</script>
```

## Overview example source

The component above is this file, unchanged:

```svelte
<script lang="ts">
  import { Image, ImageSource } from 'rta-ui';
</script>

<div class="grid">
  <Image
    src="https://images.unsplash.com/photo-1519681393784-d120267933ba?w=800"
    alt="Snowy mountain ridge at dusk"
    layout="constrained"
  />
  <Image
    src="https://images.unsplash.com/photo-1500530855697-b586d89ba3ee?w=400"
    alt="A quiet beach"
    layout="fixed"
    width={200}
    height={200}
  />
</div>

<picture>
  <ImageSource srcset="https://images.unsplash.com/photo-1470071459604-3b5ec3a7fe05?w=800 1x" />
  <Image src="https://images.unsplash.com/photo-1470071459604-3b5ec3a7fe05?w=800" alt="Fog" />
</picture>

<style>
  .grid {
    display: grid;
    gap: 1rem;
    max-width: 40rem;
  }
</style>
```

## Behaviour covered by tests

- is lazy and constrained by default
- a priority image loads eagerly with a high fetch priority
- explicit loading and fetchpriority win over priority
- renders a picture with its sources when a source child is given
- a source renders its srcset and sizes
