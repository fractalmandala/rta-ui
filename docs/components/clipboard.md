## Usage

The gallery demo, verbatim:

```svelte
<script lang="ts">
	import {
		Clipboard,
		ClipboardControl,
		ClipboardIndicator,
		ClipboardInput,
		ClipboardLabel,
		ClipboardTrigger
	} from 'rta-ui';
</script>

<Clipboard defaultValue="https://rta-ui.dev/docs/clipboard">
	<ClipboardLabel>Copy this link</ClipboardLabel>
	<ClipboardControl>
		<ClipboardInput />
		<ClipboardTrigger>
			<ClipboardIndicator />
		</ClipboardTrigger>
	</ClipboardControl>
</Clipboard>
```

## Behaviour covered by tests

- renders the Ark contract
- copy flips indicators and fires onCopy
- indicator hides when the copied flag does not match
