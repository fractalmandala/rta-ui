# Clipboard

Copy a value to the clipboard with a trigger that confirms the copy.

Port of `moduix/packages/svelte/src/components/clipboard` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Installation

```sh
pnpm add rta-ui
```

`rta-ui` ships one flat export surface, plus the tokens in `rta-ui/style.css`:

```svelte
<script lang="ts">
	import { Clipboard } from 'rta-ui';
	import 'rta-ui/style.css';
</script>
```

## Overview example source

The component above is this file, unchanged:

```svelte
<script lang="ts">
	import {
		Clipboard,
		ClipboardControl,
		ClipboardIndicator,
		ClipboardInput,
		ClipboardLabel,
		ClipboardTrigger
	} from 'rta-ui';
</script>

<Clipboard defaultValue="https://rta-ui.dev/docs/clipboard">
	<ClipboardLabel>Copy this link</ClipboardLabel>
	<ClipboardControl>
		<ClipboardInput />
		<ClipboardTrigger>
			<ClipboardIndicator />
		</ClipboardTrigger>
	</ClipboardControl>
</Clipboard>
```

## Behaviour covered by tests

- renders the Ark contract
- copy flips indicators and fires onCopy
- indicator hides when the copied flag does not match
