# Marquee

Scroll logos or announcements in a continuous loop.

Port of `moduix/packages/svelte/src/components/marquee` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Installation

```sh
pnpm add rta-ui
```

`rta-ui` ships one flat export surface, plus the tokens in `rta-ui/style.css`:

```svelte
<script lang="ts">
	import { Marquee } from 'rta-ui';
	import 'rta-ui/style.css';
</script>
```

## Overview example source

The component above is this file, unchanged:

```svelte
<script lang="ts">
	import { Marquee, MarqueeContent, MarqueeItem, MarqueeViewport } from 'rta-ui';
</script>

<Marquee speed={40} pauseOnInteraction>
	<MarqueeViewport>
		{#each [0, 1] as index (index)}
			<MarqueeContent {index}>
				{#each ['Svelte 5', 'Runes', 'CSS Modules', 'Zero dependencies'] as item (item)}
					<MarqueeItem>{item}</MarqueeItem>
				{/each}
			</MarqueeContent>
		{/each}
	</MarqueeViewport>
</Marquee>
```

## Behaviour covered by tests

- renders the ark contract
- vertically oriented marquees translate on the y axis
- paused marquees report their state
- pauseOnInteraction pauses on hover
