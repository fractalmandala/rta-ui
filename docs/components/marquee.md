## Usage

The gallery demo, verbatim:

```svelte
<script lang="ts">
	import { Marquee, MarqueeContent, MarqueeItem, MarqueeViewport } from 'rta-ui';
</script>

<Marquee speed={40} pauseOnInteraction>
	<MarqueeViewport>
		{#each [0, 1] as index (index)}
			<MarqueeContent {index}>
				{#each ['Svelte 5', 'Runes', 'CSS Modules', 'Zero dependencies'] as item (item)}
					<MarqueeItem>{item}</MarqueeItem>
				{/each}
			</MarqueeContent>
		{/each}
	</MarqueeViewport>
</Marquee>
```

## Behaviour covered by tests

- renders the ark contract
- vertically oriented marquees translate on the y axis
- paused marquees report their state
- pauseOnInteraction pauses on hover
