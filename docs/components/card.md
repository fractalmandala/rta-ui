# Card

Group a title, content, and actions on one surface.

Port of `moduix/packages/svelte/src/components/card` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Installation

```sh
pnpm add rta-ui
```

`rta-ui` ships one flat export surface, plus the tokens in `rta-ui/style.css`:

```svelte
<script lang="ts">
	import { Card } from 'rta-ui';
	import 'rta-ui/style.css';
</script>
```

## Overview example source

The component above is this file, unchanged:

```svelte
<script lang="ts">
  import {
    Badge,
    Button,
    Card,
    CardAction,
    CardBody,
    CardDescription,
    CardFooter,
    CardHeader,
    CardMedia,
    CardTitle,
  } from 'rta-ui';
</script>

<Card>
  <CardMedia>
    <div class="media"></div>
  </CardMedia>
  <CardHeader>
    <CardTitle>Field notes</CardTitle>
    <CardDescription>Reusable parts, one flat API per family.</CardDescription>
    <CardAction><Badge variant="secondary">new</Badge></CardAction>
  </CardHeader>
  <CardBody>
    <p>Cards compose from a header, a body and a footer, each of which is a plain element.</p>
  </CardBody>
  <CardFooter>
    <Button size="sm">Open</Button>
    <Button size="sm" variant="ghost">Dismiss</Button>
  </CardFooter>
</Card>

<style>
  .media {
    height: 6rem;
    background: linear-gradient(120deg, var(--moduix-accent), transparent);
  }
</style>
```
