# List

Render bulleted or numbered lists with consistent spacing and markers.

Port of `moduix/packages/svelte/src/components/list` with the same public parts and a byte-identical CSS Module, rebuilt on `src/lib/internal` instead of Ark UI.

## Installation

```sh
pnpm add rta-ui
```

`rta-ui` ships one flat export surface, plus the tokens in `rta-ui/style.css`:

```svelte
<script lang="ts">
	import { List } from 'rta-ui';
	import 'rta-ui/style.css';
</script>
```

## Overview example source

The component above is this file, unchanged:

```svelte
<script lang="ts">
  import { List, ListIndicator, ListItem } from 'rta-ui';

<List tone="muted">
  <ListItem>
    <ListIndicator />
    Zero runtime dependencies
  </ListItem>
  <ListItem>
    <ListIndicator />
    Ark-compatible data attributes
  </ListItem>
  <ListItem>
    <ListIndicator />
    CSS Modules keyed on parts
  </ListItem>
</List>

<div class="spaced">
  <List as="ol" marker="decimal" size="sm">
    <ListItem>First</ListItem>
    <ListItem>Second</ListItem>
  </List>
</div>

<style>
  .spaced {
```
